customers_200.jsonl — 200 customer records, one JSON object per line.

    python -m src.run_batch --input samples/customers_200.jsonl --capacity 40 --provider fake

THIS IS A CURATED MIX, NOT A NATURAL DISTRIBUTION.
It was assembled so that a single batch run exercises all four outcomes:

    no_action_needed                 72
    recommended                     120
    review_no_applicable_offer        3
    review_no_profitable_offer        5

In the real held-out population the split is very different -- 752 recommended,
649 no_action_needed and only 8 review cases out of 1,409 -- so 8 review customers
in 200 here is roughly 100x over-represented ON PURPOSE. If you want the true
distribution, run against the spreadsheet instead:

    python -m src.run_batch --full-base --capacity 200 --provider fake

Each record has customer_id, cltv, and a customer object with the 19 account fields
the model was trained on. There is NO ground-truth churn label in this file, so
`actual_churn` is written as -1 (unknown) and precision@K is not reported. A 0 there
would be a fabricated ground truth.
